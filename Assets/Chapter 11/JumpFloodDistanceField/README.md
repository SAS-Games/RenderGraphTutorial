# Chapter 11 - Jump Flood Distance Field

This folder provides a generic Jump Flood Algorithm (JFA) producer and a production distance-field outline consumer for URP Render Graph.

`JumpFloodDistanceFieldFeature` consumes a mask generated by `ObjectsToRenderTextureFeature` and publishes a signed-distance texture for later renderer features and shaders.

The producer does not decide what visual effect to draw. `DistanceFieldOutlineFeature` is the included production consumer; dissolve, distortion, fog, decals, interaction ranges, and other effects can consume the same distance data.

## Included Assets

- `JumpFloodDistanceFieldFeature.cs`: renderer-feature settings and orchestration.
- `JumpFloodDistanceFieldPass.cs`: initialization, jump propagation, resolve, registry publication, and debug passes.
- `JumpFloodDistanceField.shader`: all GPU stages.
- `JumpFloodDistanceField.mat`: build-safe material assigned to the feature.
- `JumpFloodDistanceField.hlsl`: reusable signed-distance shaping functions.
- `Assets/RenderTextureFeature/Core/MaskedEffect/ObjectMask.shader`: shared flat-color mask shader used by all object-mask effects.
- `Assets/RenderTextureFeature/Core/MaskedEffect/ObjectMask.mat`: shared mask material.
- `DistanceFieldOutlineFeature.cs`: one-pass signed-distance band compositor.
- `DistanceFieldOutline.shader`: alpha and additive band composition.
- `DistanceFieldOutline.mat`: build-safe material assigned to the consumer.
- `JumpFloodDistanceField.unity`: example scene.
- `JumpFloodDistanceRenderer.asset`: renderer data asset registered with the PC pipeline.

## Output Contract

The configured output texture stores one signed floating-point distance in its red channel:

```text
distance < 0  -> inside the mask
distance = 0  -> mask boundary
distance > 0  -> outside the mask
abs(distance) -> distance to the nearest boundary in input-mask pixels
```

The output name is configurable. The example publishes:

```text
_JfaSignedDistance
_JfaSignedDistance_TexelSize
```

Distance remains measured in input-mask pixels even when JFA runs at half or quarter resolution. This keeps consumer widths stable when `Downsample` changes.

## Mental Model

```text
Selected objects
    -> ObjectsToRenderTextureFeature
    -> _JfaInputMask

_JfaInputMask
    -> identify boundary seed pixels
    -> propagate nearest seeds with decreasing jump sizes
    -> calculate distance to the nearest seed
    -> apply negative sign inside the mask
    -> _JfaSignedDistance

_JfaSignedDistance
    -> outline / halo / dissolve / distortion / any consumer
```

## Renderer Order

The feature order is part of the contract:

```text
1. ObjectsToRenderTextureFeature
2. JumpFloodDistanceFieldFeature
3. One or more distance-field consumers
```

The mask pass must execute before JFA. Consumers must execute after JFA. Features at the same `Render Pass Event` follow renderer-feature enqueue order.

## Production Effect Recipes

### Wide Outline

- Placement: `Outside`
- Start: `0`
- End: desired outline width
- Softness: `1` to `3`
- Blend: `Alpha`

### Soft Halo

- Placement: `Outside`
- Start: `0`
- End: desired glow radius
- Softness: roughly half the radius
- Blend: `Additive`
- Use an HDR color and bloom for a luminous result

### Detached Ring

- Placement: `Outside` or `Both`
- Start: inner ring radius
- End: outer ring radius
- Softness: `1` to `4`

Add multiple `DistanceFieldOutlineFeature` instances after one JFA producer to create layered colors. Every additional band adds one composite pass but no additional distance-field generation.

## Smoothness And Quality

Use these settings in order when an outline looks stepped:

1. Set JFA `Downsample` to `1` only when the balanced half-resolution preset still shows stepping. This has the largest quality and GPU-cost impact.
2. Enable `Subpixel Boundary`. It estimates the silhouette edge between mask pixel centers with negligible additional cost.
3. Set `Final Refinement Passes` to `1`. This adds one JFA pass and reduces small nearest-seed propagation errors.
4. Increase the consumer `Softness Pixels` to `2` through `4` for a visibly antialiased transition.

The included balanced preset uses `Downsample = 2`, keeps `Subpixel Boundary` enabled, uses one refinement pass, and applies `3` pixels of softness. The input mask still limits quality: a low-resolution or visibly aliased mask cannot produce a perfectly smooth distance field.

For performance, keep `Max Distance Pixels` close to the largest distance any consumer needs:

```text
required maximum >= largest Band End Pixels + Softness Pixels
```

For the included 20-pixel outline with 3 pixels of softness, `32` is sufficient. A value of `256` runs several large jump passes whose results the outline never reads.

## Reusing The Output In Render Graph

Downstream renderer features should resolve and declare the distance texture as a Render Graph dependency:

```csharp
private readonly FrameTextureResolver _distanceResolver =
    new(nameof(MyDistanceEffectFeature));

// During Setup:
_distanceResolver.SetTextureName("_JfaSignedDistance");

// During RecordRenderGraph:
if (!_distanceResolver.TryResolve(
        frameData,
        out TextureHandle distanceTexture,
        out Vector4 distanceTexelSize))
{
    return;
}

builder.UseTexture(distanceTexture, AccessFlags.Read);
```

`FrameTextureResolver` resolves any texture registered in `FrameTextureRegistry`. Existing mask effects continue using the compatible `MaskedTextureResolver` subclass.

The feature also sets the configured texture as a global texture after resolve. Render Graph consumers should still use the registry and `UseTexture` so resource lifetime and ordering remain explicit.

## Reusing The Output In A Shader

Declare and sample the configured texture:

```hlsl
TEXTURE2D_X(_JfaSignedDistance);

float signedDistance = SAMPLE_TEXTURE2D_X(
    _JfaSignedDistance,
    sampler_LinearClamp,
    uv).r;
```

Include the helper file:

```hlsl
#include "Assets/Chapter 11/JumpFloodDistanceField/JumpFloodDistanceField.hlsl"
```

Examples:

```hlsl
half outsideOutline = JfaOutsideBand(signedDistance, 4.0, 1.0);
half insideOutline = JfaInsideBand(signedDistance, 4.0, 1.0);
half centeredEdge = JfaEdgeBand(signedDistance, 2.0, 1.0);
half outerGlow = JfaOutsideGlow(signedDistance, 0.08);
half insideMask = JfaInsideFill(signedDistance, 1.0);
```

## Algorithm Stages

### 1. Boundary Initialization

Each working pixel compares its mask value with eight neighbors. Pixels touching the inside/outside boundary store their own UV as a valid seed. Other pixels store `(-1, -1)`.

### 2. Jump Flood

Each jump pass checks the current seed and eight candidates at the current jump distance. It keeps the seed nearest to the current pixel.

Jump distance decreases by powers of two until it reaches one pixel:

```text
512 -> 256 -> 128 -> ... -> 2 -> 1
```

### 3. Signed-Distance Resolve

The final pass measures UV distance to the nearest seed in input-mask pixel units. Pixels inside the original mask receive a negative sign.

### 4. Publication

The output is registered in `FrameTextureRegistry`, published as a global texture, and optionally visualized.

## Performance

JFA cost grows logarithmically with the smaller of the working-texture extent and `Max Distance Pixels`. Reducing the maximum distance can therefore remove large jump passes.

```text
Core pass count = 1 initialization + ceil(log2(max dimension)) jump passes + 1 resolve
Debug view adds 1 pass
```

At half-resolution 1080p, the working size is approximately `960 x 540`, requiring ten jump passes. That produces twelve core passes or thirteen with debug enabled.

This is more expensive than a small local outline or blur, but becomes valuable when:

- Effects need large distances.
- Several effects share one distance field.
- Width changes dynamically over a large range.
- Accurate inside/outside distance is more useful than a blurred mask.

For production:

- Use `Half` precision unless visible stepping requires `Float`.
- Start with `Downsample = 2`.
- Use `Downsample = 4` on mobile or for very broad effects.
- Generate one field and share it among consumers.
- Disable debug view.
- Keep `Max Distance Pixels` no larger than consumers require.

## Multiple Distance Fields

Add multiple feature instances when masks are unrelated. Every instance must use unique input and output names:

```text
_CharacterMask -> _CharacterDistance
_InteractableMask -> _InteractableDistance
_PortalMask -> _PortalDistance
```

When several effects use the same silhouette, generate one field and reuse it instead of adding multiple JFA features.

## Limitations

- JFA is an approximation of the nearest-seed transform. Small local errors can occur near equally distant boundaries.
- Downsampling can remove very thin mask details.
- A mask touching the screen border has no information beyond the screen edge.
- The output is transient and intended for same-camera, same-frame renderer features.

## Troubleshooting

### No Distance Field

1. Confirm `ObjectsToRenderTextureFeature` is before `JumpFloodDistanceFieldFeature`.
2. Confirm input texture names match exactly.
3. Enable the mask producer's debug view and verify a white object on black.
4. Enable JFA `Contours` debug view.
5. Confirm `JumpFloodDistanceField` material is assigned.

### Distances Have The Wrong Sign

The mask is likely inverted. The expected mask is white inside and black outside.

### Thin Parts Disappear

Reduce `Downsample` or increase the source mask resolution.

### Consumers Cannot Find The Texture

Confirm the consumer is after JFA in the renderer-feature list and uses the exact `Output Texture Name`.
